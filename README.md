# dhch_weddingday

모바일 청첩장 (정적 웹페이지 + Google Sheets 저장)

## 기능
1. **참석 여부** — 신랑측/신부측, 참석/불참, 성함, 인원, 식사 여부
2. **럭키드로우** — 성함 + 전화번호 뒷자리 4자리로 응모 → 응모권 번호(No. 001…) 발급, 랜덤 한줄 응원 메세지 표시
   - 같은 이름 + 같은 뒷자리로 다시 응모하면 새 번호 대신 기존 번호를 보여줍니다.
3. **사진 갤러리** — 3열 썸네일(9장 이후 '더보기'), 탭하면 크게 보기 · 좌우 스와이프
4. **오시는 길** — 지도, 네이버지도/카카오맵/티맵 바로가기, 주소 복사, 전화, 교통 안내
5. **마음 전하실 곳** — 신랑측/신부측 계좌번호 접기·펼치기 + 복사 버튼
6. **캘린더에 추가** — 휴대폰 캘린더(.ics, 하루 전 알림 포함) / 구글 캘린더
7. **방명록** — 축하 메세지 작성·목록(5개씩 더보기). 부적절한 글은 `방명록` 시트에서 행을 삭제하면 사라집니다.
8. **공유하기** — 카카오톡 공유 카드, 링크 복사

## 카카오톡 공유 설정
1. [developers.kakao.com](https://developers.kakao.com) → 내 애플리케이션 → 앱 추가
2. **플랫폼 > Web**에 배포 주소 등록 (예: `https://<계정>.github.io`)
3. **앱 키 > JavaScript 키**를 `config.js`의 `kakaoKey`에 입력
4. `config.js`의 `share` (제목·설명·대표 이미지 주소) 수정

키가 없으면 카카오톡 버튼은 기기 기본 공유창 또는 링크 복사로 대신 동작합니다.

**링크 미리보기:** 카카오톡에 링크만 붙여넣을 때 보이는 미리보기는 `index.html` 맨 위의 `og:` 태그를 읽습니다.
배포 주소가 정해지면 `og:image`, `og:url`을 실제 주소로 바꿔주세요 (이미지는 `images/share.jpg` 등으로 추가).
카카오톡은 미리보기를 캐시하므로, 수정 후에는 [카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing)에서 캐시를 초기화하세요.

## 디자인 테마
`config.js`의 `theme` 값으로 5가지 중 선택합니다.

| 값 | 분위기 |
|---|---|
| `classic` | 클래식 에디토리얼 — 아이보리 · 블랙 · 골드, 세리프 타이포 |
| `romantic` | 로맨틱 플라워 — 연핑크 · 라벤더, 아치형 사진, 꽃잎 날리는 효과 |
| `minimal` | 모던 미니멀 — 화이트 · 차콜 · 세이지, 큰 날짜 숫자, 왼쪽 정렬 |
| `winter` | 윈터 감성 — 딥그린 · 버건디 · 크림, 눈 내리는 효과 |
| `ginkgo` | 은행잎 — 한지 질감 · 먹색 · 은행 노랑, 붓글씨 서체, 囍 낙관, 은행잎 떨어지는 효과 (현재 설정) |

**비교해 보기:** 주소 뒤에 `?theme=romantic`처럼 붙여서 열면 화면 아래에 테마 전환 버튼이 나타납니다.
하객에게 보내는 주소에는 `?theme=`를 붙이지 마세요.

공통 레이아웃은 `style.css`, 테마별 색상·글꼴은 `themes.css`에 있습니다.
커버의 영문 이름은 `config.js`의 `groom.en`, `bride.en`에서 수정하세요.

## 사진 바꾸기
- **커버 대표 사진:** `images/`에 세로 사진(3:4 비율 권장)을 넣고 `config.js`의 `coverImage`를 그 경로로 바꾸세요.
- **갤러리:** `images/gallery/`에 사진(jpg 등)을 넣고 `config.js`의 `gallery` 목록을 그 파일명으로 바꾸세요. 첫 번째 사진은 크게 보입니다.
모바일 로딩 속도를 위해 사진은 가로 1200px 이하, 장당 500KB 안팎으로 줄여서 넣는 걸 권장합니다.

## 파일
| 파일 | 설명 |
|---|---|
| `config.js` | 이름, 날짜, 장소, 인사말, 응원 메세지 목록, API 주소 — **여기만 수정** |
| `index.html` / `style.css` / `script.js` | 청첩장 화면 |
| `themes.css` | 디자인 테마 |

| `apps-script/Code.gs` | Google Sheets 저장용 백엔드 |

## 응답 저장 설정 (Google Sheets)
1. 새 구글 스프레드시트 생성 → **확장 프로그램 > Apps Script**
2. `apps-script/Code.gs` 내용 붙여넣고 저장
3. **배포 > 새 배포 > 유형: 웹 앱**, 실행 사용자 `나`, 액세스 권한 `모든 사용자` → 배포
4. 나오는 웹 앱 URL을 `config.js`의 `apiUrl`에 입력

> 이미 배포했다면 `Code.gs`를 업데이트한 뒤 **배포 > 배포 관리 > 수정(연필) > 버전: 새 버전**으로 다시 배포해야 반영됩니다.

`apiUrl`을 비워두면 **데모 모드**로 동작합니다 (응답이 그 기기 브라우저에만 저장되고 서버로 가지 않음).

응답은 스프레드시트의 `참석여부`, `럭키드로우`, `방명록` 시트에 쌓입니다. 당일 추첨은 `럭키드로우` 시트의 응모번호 중에서 뽑으면 됩니다.
